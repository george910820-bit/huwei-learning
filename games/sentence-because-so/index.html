虎尾句型小教室

因為……，所以……

因為原因，所以結果。

「因為」後面說為什麼（原因），「所以」後面說後來怎麼了（結果）。先看影片裡的三個例子，再玩句型遊戲自己造句。

▶ 看影片🎮 玩句型遊戲

🎬 影片（約 3 分鐘）

  • 貓頭鷹老師介紹句型：原因、結果
  • 例子一：天氣很熱 → 小熊流了很多汗
  • 例子二：下大雨了 → 小兔撐雨傘
  • 例子三：肚子好餓 → 小貓吃麵包
  • 每個例子最後都有「換你念念看」

🎮 句型遊戲（6 題）

  • 第一關：影片裡的 3 個句子
  • 第二關：看 3 段新短片自己造句（想睡覺、考一百分、跌倒）
  • 排字卡：點選或拖拉；用說的：老師按對錯
  • 最後有成績頁，可截圖當評量紀錄

👩‍🏫 老師小提醒

  • 字卡裡有「錯的原因」和「錯的結果」，放錯位置會提示「這是結果，要放在所以後面」。
  • 「挑戰」難度連「因為」「所以」也要自己排。
  • 用說的：需要 Chrome、網路、麥克風。辨識結果只是參考。
